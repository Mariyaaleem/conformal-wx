# notebooks/

Exploratory Colab notebooks used while developing the project. They are kept for transparency.

The paper's numbers are reproduced by the scripts in the repository root, not by these notebooks:
`./run_all.sh reproduce` (see the top-level README). The bootstrap tables, heterogeneity-aware VIF,
threshold sweep and bias-by-year table that were first computed in ad hoc notebook cells are
regenerated by `05_bootstrap_tables.py` and `06_extra_diagnostics.py`.

Notebooks contain Drive paths and may not run outside the original Colab environment.
